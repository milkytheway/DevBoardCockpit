## 一 · Critical 的处置（**4 条，全部接受** ✓）

### C-1 · `args_summary` 的白名单按参数名筛 —— **实现不了它声称的边界** ✓

**接受** ✓ —— **这是一条安全底线** ✓。

**为什么评审是对的** ✓：
- `path` 在 `file_read` 里是**板上路径**（可给 ✓），在 `script` 里是**宿主路径**（不可给 ✓）
  → **同一个参数名，两种性质** ✓ → **按参数名筛必然放错** ✓
- 白名单还**误伤**了 `proc_stat` 的 `stat_path` / `cpuinfo_path` ✓（**最常用的 reader** ✓ → agent 拿到空对象 ✓）
- 白名单里的 `type` **没有任何 kind 用** ✓（`thermal_zone` 的是 `type_map` ✓）

**处置** ✓：

| kind | 给 agent 的参数 | 挡掉的 |
|---|---|---|
| `proc_stat` | `stat_path`, `cpuinfo_path` | — |
| `meminfo` | `path` | — |
| `devfreq_load` | `path`, `measure` | — |
| `rknpu_load` | `path` | — |
| `thermal_zone` | `glob`, `type_map` | — |
| `file_read` | `path`, `glob`, `format`, `strip_trailing_null` | — |
| `exec_regex` | `pattern`, `format` | **`command`** |
| `script` | **（空）** | **`path`, `interpreter`, `format`** |

**总则**（写进契约）：
> **放行表按 `(kind, 参数名)` 判定** ✓ —— **不按参数名单独判定** ✓
> （`path` 在 `file_read` 是板上路径 ✓，在 `script` 是宿主路径 ✓）。
> **不在表里的参数一律不给** ✓（封闭表 ✓，不是「先给再筛」✓）。
> `script` 的 `args_summary` **恒为空对象** ✓ —— agent 只知道「这个量来自一个脚本」✓。

**连带** ✓：M-1 ✓（`script` 没有 `command` ✓ · 是 `path`+`interpreter` ✓）、M-2 ✓（`type` → `type_map` ✓）—— **随 C-1 一起改** ✓。

### C-2 · `missing_tags` 的口径在宿主侧算不出来 —— **接受** ✓

**接受** ✓ —— 评审把两件事都验实了 ✓：
- 「模式 → 具体名」这个方向**宿主侧不存在** ✓（只有反方向 ✓）
- **更要命的**：store 里**根本没有「读不到」的那批具体名** ✓ —— 采样失败时通配 tag 被跳过 ✓
  → 所以「store 里有但状态不对」这条判据**只对已经成功绑出来的具体名成立** ✓
  → 而「整个 reader 挂了 → 通配实例不标 stale → store 里还是 ok」→ **卡片不会被判 degraded** ✓ → **agent 被骗** ✓

**处置** ✓ —— **拆成两个字段** ✓：

| 字段 | 语义 | 判据 |
|---|---|---|
| **`missing_tags`** | 这张卡要的、**当前板型包根本没有**的 tag | **模式级** ✓ —— 对 `permissions.read` 的每个模式 P，若当前包的所有 reader 的 provides 模式里**没有一个覆盖 P** → **P 整条记进去** ✓（**记模式本身** ✓，**不展开** ✓） |
| **`unreadable_tags`** | 声明了、包也提供了、但**现在读不出来**的 tag | **具体名级** ✓ —— TagStore 里**该具体名存在**且 status ≠ `ok` ✓ · **只列具体名** ✓ |

**免责**（写进契约）：
> **「读不到」与「不存在」是两件事** ✓（同 `spec/01` §2.1 的 `unavailable` vs `error` ✓）。
> **通配 tag 的实例在 store 里缺席时，不得据此判定「缺失」** ✓ ——
> 采样器**按契约不猜具体实例名** ✓。

**`degraded`** = `missing_tags` 非空 **或** `unreadable_tags` 非空 ✓。

**连带欠账** ✓：通配实例在刷新失败时**不标 stale** ✓（与 `spec/01` §2.3「刷新停了 → stale」对不上 ✓）
→ 记进 `docs/06` 的 **C27** ✓（**记，不在本轮改** ✓ —— 改它要动采样器 ✓ 那是另一个变更 ✓）。
