## 4. 为什么整体推翻重来（用户决定，2026-11-12）

1. **Qt Widgets 的天花板**：卡片是任意网页 + iframe 沙箱 + 白名单 API + 热插拔，
   这套东西在 Qt Widgets 里没有对应物；PySide6-Essentials 也不含 WebEngine。
2. **布局编辑器**：react-grid-layout 这类现成方案在 Web 生态里，在 Qt 里要自己写。
3. **AI 结对**：agent 写 React/HTML 的可靠性明显高于写 QWidget，
   而「卡片就是产品」——产品形态决定技术栈。
4. **MCP server 必须与 GUI 同进程**：这是硬约束，见 `docs/05-决策记录.md` D2。

## 5. 旧工程的已知技术债（新工程不要继承）

| 债务 | 说明 |
|---|---|
| `main_window.py` 39 KB | 单文件塞了窗口、会话、快捷命令、资源条、文件浏览 |
| 资源条是固定控件 | 不可拖拽、不可分享 |
| 指标是「整板一次快照」 | 能跑但不可组合；新工程要按 tag 组合 |
| 快捷命令是命令字符串 | 没有分级、没有回读、没有审计 |
| 无版本化的 profile | 用户手改 JSON 无 schema 校验，坏文件只能跳过并报错 |
