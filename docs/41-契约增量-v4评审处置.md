**处置**：

| # | 事 | 状态 |

> 却一个字都没断言** ✓ → 拆成三条各有各的断言 ✓（**测试名不许承诺它不检查的东西** ✓）。

### C-2 · C1 写死了机制 → **改措辞** ✓

**接受** ✓。评审查得对 ✓：`spawn.ts` 有三级升级 ✓，
但 `ssh` 是**关通道** ✓、`adb` 杀的是**本地客户端** ✓、
`serial.ts:332-334` **自己写着「串口上没法杀远端的进程」** ✓
→ 契约写死「SIGTERM→200ms→SIGKILL」**是 4 种传输里 3 种的假话** ✓。

**新措辞**（进契约 ✓）：

> **取消 = 宿主*请求*中止在飞的那一步** ✓。
> **能不能真的停，取决于传输与远端** ✓ —— 契约**不承诺**「进程一定死」✓
> （串口上做不到 ✓ —— 那不是一条 shell 连接 ✓；ssh/adb 上取决于远端 ✓）。
> 契约承诺的是两件：**宿主不再等** ✓ + **时间线如实说** ✓。

**同时补一条**（评审没提、但必须一起写 ✓）：动作的 `reason` 封闭表里**加 `cancelled`** ✓
—— 不然「被取消」在动作层会被说成「回读不符」✓（**撒谎** ✓）。

### C-3 · R2 + R6 = 宿主替包删文件 → **补两条子规则** ✓

**人看不到真实路径** ✓ → 而 R6 让清理命令**不过地板、不过确认** ✓ → **后门** ✓。

**R6 改成三条**：

| # | 规定 |
