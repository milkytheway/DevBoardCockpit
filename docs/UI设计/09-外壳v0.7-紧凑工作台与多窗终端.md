## 一、五个要求的落点

### 1. 顶部压扁：标题与控件同一行

- `WorkbenchPage.tsx` 页头改为 `<header className="page-head page-head--compact">`，
  **删掉 eyebrow 与小字解释**，只剩 `h1`「总览」+ 右侧的密度 / 刷新 / 卡片库。
- `visual.css`：全局 `.page-head` 单行对齐（`align-items:center`、`gap:12px`）、
  `.page-head__title` 20px、`.page-head__eyebrow/.page-head__sub { display:none }`、
  `.app-scroll` 上边距 16→12px。
- 其他页面同样受益；文件页的「正在上传…」note 仍在右侧 action 区。

### 2. 二级栏：状态收窄 + Pinned + 分组

- 状态组压成一行：隐藏组标题与 hint，只剩状态点 + 「采样中」；卡片目录获得更多高度。
- `cards.ts`：`CardLook` 增加 `group` 与 `tags`；六个内置卡归入
  `CARD_GROUPS = ['性能','内存与温度','系统','自定义']`，未知卡落「自定义」。
- `nav.ts`：卡片目录在 `cards` 组内按 **PINNED → 分组标题 → 组内 localeCompare**
  排序；行标签用 `look.name`，hint 保留 `cardId · 已在主区 · 点击撤下` /
  `cardId · 点击摆进主区`（e2e 与 M75 依赖的 `slotKey` 锚点原样保留）。
- `Secondary.tsx`：组内渲染 `secondary__section` 小标题；悬停卡片行右侧出现
  **pin 星**（`secondary__pin`，aria-label「置顶/取消置顶 <名称>」），
  `Shell.tsx` 用 `devboard.pinnedCards`（localStorage）记住置顶集合。

### 3. 右侧详情：采集行为 / 原始读数 / 活动

- `data.ts` 新增 `useTagStream(limitPerTag=120)`：`tagsReadings()` 快照 +
  `onTagChanged` 推送，按 tag 留最近 120 条；返回
  `{readings, latestFor, historyFor, sampleCount}`（只存在 renderer 内存）。
- `DetailPanel.tsx` 三页签：
  - **采集**：该卡声明的 tags（`cards.ts` 的 `tags`）逐条显示最新值、状态、
    年龄、观测周期（取最近 6 条间隔的中位数）；实例 连接/实例/**布局 w×h**/状态；
    沙箱 pill（`sandbox="allow-scripts"`、opaque origin、CSP、存储代管）。
  - **原始读数**：最新 `TagReading` 的 JSON + 最近 30 条采样流水
    （时间 / 状态 / tag / 值 / seq），方便对每一次读数回查。
  - **活动**：沿用宿主 activity，过滤到该卡；并注明卡片运行时日志要等
    M6 的面板 IPC（renderer 现在拿不到 main 的 `CardRuntimeLog`）。
- 未知卡片（不在 `cards.ts` 映射里）显示「宿主不向 renderer 暴露 manifest」
  的提示，**不编造**它的采集清单。
- 详情仍是覆盖式、左缘可拖 320–640px、可关闭、切页自动关。

### 4. 终端：单窗 / 左右 / 四宫

- `TerminalPage.tsx` 重写：`TerminalLayout = 'single' | 'split' | 'quad'`，
  容量 1/2/4；`paneIds` 保留存活会话、补当前会话、补其余到容量；
  页头右侧是排列切换 + 「n / m 个会话在窗格里」。
- 两个及以上会话时每条窗格有 header：label、sessionId 前 6 位、「当前」chip、
  关闭按钮；点窗格/侧栏会话切换焦点。所有会话**始终挂载**，未显示的是
  `hidden` 但保持 `display:block; opacity:0`（见 §四的 xterm 坑）。
- 只开 1 个会话时，即使选了「左右」也占满整宽（`data-panes="1"` 覆盖）；
  2 个会话选「四宫」时排成单行两列。

### 5. 磨砂背景、半透明卡片、悬浮感

- `.app-shell`：多层 radial（accent 44% / accent-2 34% / series-3 28% /
  series-5 16%）压在 `#06080b` 上；卡片是
  `color-mix(surface 46%, transparent)` + `backdrop-filter: blur(30px) saturate(165%)`，
  头部/底部 24% 透明。
- 强调色只用于状态与数据；卡片悬停 `translateY(-2px)` 并加深环境阴影，
  选中卡保留蓝色 rim + 四角抓柄。
- 状态栏/rail/二级栏/详情：surface 46% 透明 + blur(26px) saturate(150%)。
- 对比度仍以 `--cockpit-*` 语义色为准（正文/语义色 ≥4.5:1，控件边框 ≥3:1）。

## 四、已知问题 / 下一期

1. **卡片运行时日志**：详情目前只有 renderer 能看到的 tag 流与 activity；
   真正的 `CardRuntimeLog` 在 main，等 M6 的面板 IPC 接上后再补「卡片 log」页。
2. **xterm 的 `dimensions` pageerror**：xterm 在 `display:none` 的宿主上会从
   内部 Viewport observer 抛 `Cannot read properties of undefined (reading 'dimensions')`。
   处理：未显示的 pane 改成 `display:block; opacity:0; pointer-events:none`（保尺寸），
   并在 `TerminalView.tsx` 用 `safeFit()` 跳过 <20px 的宿主。开发态仍偶发一条，
   不影响功能；等 xterm 升级或改为只挂载可见会话时再消除。
3. **假设备的终端 banner**：偶发首屏只有光标（fake 连接建立早于 xterm 订阅的时序），
   输入命令后正常；真板串口/SSH 不受影响。
4. 浅色主题仍禁用（卡片主题通道未接，见 `08` §四）。
