## 一、六个要求的落点

1. **亮色模式 + 磨砂背景**
   - 主进程新增主题通道：`IPC.themeSet` / `CockpitApi.setTheme`（preload 暴露；
     `main/index.ts` 记住 `shellTheme` 并传给 `createCardWiring` 的 `theme()`）。
   - renderer `Shell.tsx` 切主题时先 `applyTheme`，再等 `setTheme` 确认，
     最后才让卡片 iframe 重挂（`cardTheme`）——避免 iframe 抢跑到旧主题。
   - `material.ts` 的 canvas 档修复：暗色 `#06080b`、浅色 `#F5F6F7`
     （旧版 light 误写成深色，导致浅色画布发黑）；`npm run gen:theme` 重新生成。
2. **按 UIrefactortest 的 shadcn 中性色纪律规范配色**
   - 借鉴其「用一组中性 token，状态色只做点睛」：卡片图标 tile、状态点、分隔线、
     遮罩全部走 `--cockpit-*` / `--shell-mat-*` / `color-mix`；不引入 Tailwind/antd。
   - 颜色只表达状态；身份色（`--card-tone`）从 `CardShell` 与 `DetailPanel` 删除。
3. **卡片顶部统一配色**
   - 卡片壳的图标 tile 统一中性（hover 才 accent）；状态 chip 改为**点**（保留 title /
     aria-label 文案）；`data-tone` 删除。
4. **暗色磨砂背景收敛为一团弥散光**
   - `.app-shell`：`radial-gradient(150% 122% at 50% -22%, accent 34%, transparent 66%)`
     + `--shell-mat-canvas`；浅色同位置 accent 16%。
   - accent-2 / series-3 / series-5 的背景光晕删除。
5. **卡片内部克制、去掉「沙箱运行」**
   - 六张卡统一为「1 主读数 + ≤2 辅助 + 1 状态行」，删掉仪表/双环/sparkline/
     段条/多块 summary 等；趋势与原始数据移到右侧详情。
   - `CardShell` 的 footer（「沙箱运行」+ 实例短码）整块删除。
6. **二级栏顶部合并 + 分组折叠；App 顶部去掉「采样中」**
   - `StatusBar` 删除 runtime chip（顶部只留品牌 / 卡片数 / 搜索 / 主题）。
   - `Secondary` 头部一行：页面名 + 状态点/「采样中」+ 板名 + 收起；
     组标题与卡片分区标题可点击折叠，折叠集合存
     `localStorage['devboard.collapsedSections']`。
   - `nav.ts` 删除自带的 status 组；卡片按 Pinned → 性能 → 内存与温度 → 系统 排序。

## 四、已知问题 / 下一期

1. **xterm 的 `dimensions` pageerror**：切换页面/卸载终端时偶发
   `Cannot read properties of undefined (reading 'dimensions')`；宿主 pane 尺寸为 0
   或 xterm 内部 observer 在卸载时序上触发。`TerminalView` 已用 `safeFit` 跳过 0 尺寸，
   不影响功能；后续改为「终端页常驻、只隐藏」或等 xterm 修复。
2. **慢采样组首屏空窗**：`board.model` 这类慢组 tag 在订阅后要等下一轮采样，
   卡片会先显示「等待第一次采样」；后续可在订阅成功时主动 `tags.get` 一次快照。
3. **卡片运行时日志**：详情当前只有 renderer 的 tag 流与 activity；main 的
   `CardRuntimeLog` 需要 M6 的面板 IPC 才能展示。
4. Q3/Q4（遮罩与高光档位）仍未收敛；Q6（accent-2 契约地位）未动。
