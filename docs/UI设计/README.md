# UI 设计（`docs/UI设计/`）

> ## ⚠️ 本版视觉设计已作废（2026-11-14 · 用户拍板）
>
> **外壳交给 DSH 重写**，当前这版的界面设计**不再作为目标**。
>
> **但下面三样东西活着**，且**不是视觉问题**：
>
> | 活着的东西 | 为什么它不在作废范围内 |
> |---|---|
> | **机制**：`src/main/cards/*`、bridge 脚本、preload 的 API、token 三层 | 卡片宿主与跨进程接口——**外壳换了它们不动** |
> | **契约里的 15 个 `--cockpit-*` 别名**（`spec/03` §6.3） | **卡片靠它们活着**（卡片自己的 CSS 只能用这些变量） |
> | **[`07-外壳接口清单.md`](07-外壳接口清单.md)** | **交接件**：新外壳必须接上的九件事 + 不能做的五件事 + e2e 的稳定钩子。**写完外壳先看它** |
>
> **换肤不等于重写**：视觉要换，改 `src/shared/theme/seed.ts` 的**值**就行
> （种子 → 映射 → 别名三层就是为这个造的）——见 `05` §六。
