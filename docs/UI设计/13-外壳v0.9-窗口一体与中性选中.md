## 一、五点落点

### 1. 顶部不再显示「M5b」「6 / 6 张卡片」

整条 `StatusBar` 删除（`src/renderer/shell/StatusBar.tsx` 无引用后删除）。
品牌、版本号、卡片计数、runtime chip 都不在应用内重现。

### 2. 取消应用自绘顶栏，与系统窗口一体

- `src/main/index.ts`：`BrowserWindow` 使用
  `titleBarStyle: 'hidden'` + `titleBarOverlay: { color, symbolColor, height: 40 }`，
  颜色取 `SEEDS[theme]['bg-0'] / ['text-0']`；`Menu.setApplicationMenu(null)` 去掉菜单栏；
  `theme:set` 时对所有窗口调 `win.setTitleBarOverlay(...)` 跟随主题重着色。
- renderer：`Shell.tsx` 顶部放一条 `.window-drag`（40px、`-webkit-app-region: drag`），
  应用内容从 40px 以下开始；窗口按钮由系统绘制在右上角，视觉上与画布同底色。
- 搜索命令入口从顶栏移到左侧 rail 底部（SearchIcon「搜索」），Ctrl K 仍可用。
- `index.html` 的 `<title>` 保持「开发板驾驶舱」：标题栏不可见，但 Windows 任务栏和
  e2e 的 `toHaveTitle(/开发板驾驶舱/)` 仍用它。

### 3. 选中边框/二级栏边框改中性色

- rail 选中：表面 text 9%、边框 `color-mix(text 28%, hairline)`。
- 二级栏选中：表面 text 10%、边框 `text 30%`、左侧 2px 竖条
  `color-mix(text 52%, border-strong)`；选中图标/pin/分组提示都不再使用 accent。
- 卡片选中：`text 40%` 边框 + 1px `text 22%` 内环；拖拽占位/缩放手柄也用 text 色。
- 终端活动窗格：`text 30%` 边框 + `text 12%` 内环。
→ 蓝色只留给数据与状态（accent 用于图表/运行点），不再表示「选中」。

### 4. 全局禁止拖选，只有终端/日志可选

- `src/shared/theme/base-css.ts`（注入到每张卡片）与 `visual.css` 都设置
  `html, body { user-select: none }`；输入框、textarea、select、contenteditable、
  `.xterm`、`.terminal__pane`、`.page--logs`、`.activity-list` 恢复 `text`。
- 页面切换按钮、卡片标题、半透明面板等拖拽时不再带出蓝色文字选区。

### 5. 亮色磨砂加强

- 亮色画布：单团 accent bloom（128%×104%，34%）+ 纵向
  `surface 38% → bg 78%` 渐变，让玻璃有可模糊的明暗层次。
- 亮色卡片：表面 `surface 46%` + `backdrop-filter: blur(36px) saturate(200%)`，
  内高光与玻璃阴影沿用材质层 `--shell-mat-*`。
- 主题切换：renderer 先 `theme:set` 通知 main，等 main 确认后再用 `cardTheme`
  重挂卡片 iframe，避免「外壳已浅色、卡片还在深色」的中间帧。

## 四、已知 / 下一期

3. 卡片内文字同样不可选（这是「全局禁选」的应有含义）；若将来要允许卡片内选择，
   在卡片 theme.css 里单独开 `user-select` 白名单。
4. 既有问题仍在：xterm `dimensions` 偶发 pageerror、慢采样组首屏空窗、
   卡片运行时日志待 M6、Q3/Q4 档位未收敛。
