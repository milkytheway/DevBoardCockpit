## 一、方向

- **保留 Claude 的信息架构**（六个页面、左侧 rail + 二级栏、主区卡片、独立详情）。
  这套 IA 是对的，问题只在「看起来像没画完」。
- **视觉回到 DSH v2 车机质感**：近黑底、渐变卡面、1px 清晰描边、顶部高光、
  极轻环境光、14px 圆角、只用 `--cockpit-*` 取色；不做玻璃拟态/弥散阴影。
- **只动 renderer 与 `cards/`**：`src/main/**`（除允许的零改动）、`broker.ts`、
  契约别名都不碰。浅色主题因为主进程没有主题通道，**先禁用**而不是假装支持。

## 二、改了什么

### 外壳（`src/renderer/shell/`）

- `visual.css`（新增，约 2.4k 行）：车机质感视觉层，叠在 `shell.css` 之后；
  布局、卡片材质、rail/secondary、卡片壳、详情、library、文件页、日志、终端、
  palette、滚动条、浅色兜底。
- `StatusBar.tsx` / `Rail.tsx` / `Secondary.tsx`：品牌区、SVG 图标、页标题 +
  分组计数 + 可折叠二级栏；折叠状态存 `localStorage`，折叠后保留浮出展开按钮。
- `cards/CardShell.tsx`：卡片壳重做（图标、中文名、note、状态 chip、菜单），
  拖拽手柄改为 `pointerdown/up` 距离判定，**单击卡片可打开详情**（修 P0）。
- `cards/CardGrid.tsx`：行高 64 / 44（舒适 / 紧凑）、间距 14；拖拽时显示落点。
- `detail/DetailPanel.tsx`：覆盖式详情（不挤压工作区），左缘可拖 320–640px，
  可关闭，切页自动关；内容改为「实例 / 沙箱 / 入口 / 该卡活动」，去掉长段说教。
- 六个页面：页头统一（eyebrow / 标题 / 描述 / 操作），空态、加载态、错误态成套；
  文件页让旧 FileBrowser 撑满整页；终端页整页 xterm；日志页修好行网格。
- `cards.ts`：卡片展示名 / tone / 图标的单一映射（shell 与详情共用）。

### 卡片（`cards/`，fake dev 下全部有数）

| 卡 | 尺寸 | 视觉 | 读的 tag |
|---|---|---|---|
| `cpu-usage` | 6×5 | 半圈仪表 + 8 核竖条 + governor + 60s spark | cpu.usage, cpu.core.*.usage/cluster, cpu.governor |
| `gpu-npu` | 4×5 | 双环 + 频率/温度 facts；NPU 不可用如实显示 ⊘ | gpu.usage/freq, npu.usage, temp.gpu/npu |
| `memory` | 4×4 | 大百分比 + 18 段条 + 60s spark + 已用/可用/总量 | mem.usage/used/total/available |
| `thermal` | 3×4 | SoC hero + GPU/NPU 70/85 阈值条 | temp.soc/gpu/npu |
| `core-load` | 5×4 | 平均/峰值/总占用 + 8 核柱状（A55/A76 分组） | cpu.usage, cpu.core.*.usage/cluster |
| `board-identity` | 4×4 | 型号 + governor + GPU 频率 + 两路背光条 | board.model, cpu.governor, gpu.freq_hz, backlight 0/1 |

所有卡片 CSS 只用 `--cockpit-*`，七态（ok/pending/stale/unavailable/error/
degraded/broken）按宿主样式类显示；卡片脚本用 `subscribeWithRetry` 兼容
bridge 私有端口的异步接线（首个 subscribe 可能 `not_connected`）。
