# 尖兵 · 卡片沙箱 + CSP + 桥接（Electron 34 实测）

> **日期**：2026-11-13
> **作者**：Codex
> **为什么有这份**：M5（卡片框架）的设计里有一处**没人做过的技术选择**——
> 卡片跑在 sandbox iframe 里，`cockpit.*` API **怎么进得去**。
> 契约 §六 明写「本轮规格不锁这一点」。
>
> **所以这不是推理，是实测。** 本文档记录尖兵源码与全部输出，可原样复跑。
> 结论与建议见 `docs/20-M5设计评审-架构优化建议.md`。

---

## 怎么复跑

```powershell
# 任意目录放三个文件（见下），然后：
& .\node_modules\electron\dist\electron.exe <那个目录>
# 结果写在 <那个目录>\result3.log
```

> 注意：Electron 是 **Windows GUI 子系统程序**，`console.log` **不会**出现在父终端里
> ——尖兵因此把结果写进文件。（第一次跑就栽在这儿。）

## 实测结果

### 第一轮：卡片自己的 ES Module 能不能跑？

**第一跑失败**——全部资源按 `text/html` 发：

```
Failed to load module script: Expected a JavaScript module script but the server
responded with a MIME type of "text/html". Strict MIME type checking is enforced
for module scripts per HTML spec.
```

**改正 MIME 后跑通**：

```
PROTOCOL req=cockpit://card/a.html  found=true
PROTOCOL req=cockpit://card/card.js found=true
PROTOCOL req=cockpit://card/lib.js  found=true
MSG_FROM_CARD {"marker":"MODULE_LOADED", ...} origin=null           ← iframe A（不透明源）
MSG_FROM_CARD {"marker":"MODULE_LOADED", ...} origin=cockpit://card ← iframe B
```

> **结论 1**：`script-src 'self'` **在 `sandbox="allow-scripts"`（不透明源）下照样匹配**，
> 卡片自己的 `<script type="module" src>` 与**相对 import** 都能跑。
> **（我原本的假设是错的——以为不透明源下 `'self'` 匹配不到任何 URL。幸好做了实测。）**
>
> **结论 2**：**协议 handler 必须按扩展名给正确 MIME**（`.js` → `text/javascript`），
> 否则 module script 直接被拒。设计文档没写这条。

### 第二轮：隔离到底成不成立？

卡片里跑 6 个探针：

| 探针 | iframe A（不透明源） | iframe B（allow-same-origin） |
|---|---|---|
| 读 `parent.document.title` | **BLOCKED: SecurityError** | **BLOCKED: SecurityError** |
| 读 `window.top.location` | **BLOCKED: SecurityError** | **BLOCKED: SecurityError** |
| `localStorage.setItem` | **THROWS: SecurityError** | OK |
| `fetch('https://example.com')` | **BLOCKED: TypeError** | **BLOCKED: TypeError** |
| `new WebSocket('wss://…')` | 构造不抛错，**连接被 CSP 拦掉** | 同左 |
| `new Image(); img.src='https://…'` | 构造不抛错，**加载被 CSP 拦掉** | 同左 |

宿主侧看到的 CSP 违规（**能被 `console-message` 抓到**）：

```
Refused to connect to 'https://example.com/' because it violates the following
Content Security Policy directive: "connect-src 'none'".
Refused to connect to 'wss://example.com/' because it violates ... "connect-src 'none'".
Refused to load the image 'https://example.com/x.png' because it violates ... "img-src 'self' data:".
```

> **结论 3**：**隔离成立**——两种变体都碰不到宿主 DOM。
> **结论 4**：**CSP 拦得住 fetch / WebSocket / img 外传**，且**违规能被宿主捕获**
> → 契约 §6.1 的「CSP 违规进运行时日志」**可行**。
> **结论 5**：**卡片之间的隔离只有变体 A 有**——变体 B 下所有卡共享 `cockpit://card`
> 一个源，**A 卡能读 B 卡的 localStorage**。契约 §6.2 承诺的「每卡一个命名空间、互不可见」
> **只有变体 A 能兑现**。
> **结论 6**（细节）：`new WebSocket()` / `new Image()` **构造时不抛错**，
> CSP 是在连接/加载时才拦 → 卡片不能靠 `try/catch` 判断「有没有网」。

### 第三轮：桥接骨架能不能跑通？

```
PARENT_cockpit_type=object where=MAIN_FRAME      ← preload 在**主帧**里是好的
BRIDGE_GRANTED to=A origin=null
BRIDGE_GRANTED to=B origin=null
CARD_REPORT {"report":"GOT","value":{"value":37.2,...},"cockpitType":"object"} sourceCard=A
CARD_REPORT {"report":"GOT","value":{"value":37.2,...},"cockpitType":"object"} sourceCard=B
```

桥接做法（**没有 nonce、没有 token**）：

1. 卡片里的 bridge 脚本（同源，由 `cockpit://` 提供）发 `parent.postMessage({type:'cockpit-hello'}, '*')`；
2. 宿主**只用 `event.source` 认人** → 找到是哪个 iframe → 建 `MessageChannel`；
3. 宿主 `iframe.contentWindow.postMessage({type:'cockpit-port'}, '*', [port2])` 把端口转过去；
4. 卡片在私有端口上跑请求-响应，`window.cockpit.tags.get('cpu.usage')` 拿到值。

> **结论 7**：**Electron 的 preload 不进子 iframe**（主帧 `typeof window.cockpit === 'object'`，
> 两张卡里都是 `undefined`）→ **postMessage 桥是必须的**，没有第二条路。
> **结论 8**：**MessagePort 能转进不透明源的 iframe**；
> **结论 9**：**`event.source` 能准确认人** → **不需要 nonce**
> （卡片拿不到别的卡的 window 引用，所以冒充不了）。

## 尖兵源码

### `main.js`（主进程）

```javascript
const { app, BrowserWindow, protocol } = require('electron');
const path = require('node:path');
const fs = require('node:fs');
const LOG = path.join(__dirname, 'result3.log');
const out = (m) => fs.appendFileSync(LOG, m + '\n');
fs.writeFileSync(LOG, '');

protocol.registerSchemesAsPrivileged([
  { scheme: 'cockpit', privileges: { standard: true, secure: true, supportFetchAPI: true, cspEnabled: true } },
]);
const CSP = "default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self' data:; connect-src 'none'; form-action 'none'; frame-src 'none'; base-uri 'none';";

// ---- 卡片侧的 bridge（由 cockpit:// 同源提供，script-src 'self' 允许） ----
const BRIDGE = `
let port = null;
const pending = new Map();
function ask(type, payload) {
  return new Promise((resolve, reject) => {
    const id = Math.random().toString(36).slice(2);
    pending.set(id, { resolve, reject });
    port.postMessage({ id, type, payload });
  });
}
window.addEventListener('message', (e) => {
  // 宿主把 MessagePort 交给本窗口
  if (e.data && e.data.type === 'cockpit-port' && e.ports && e.ports[0]) {
    port = e.ports[0];
    port.onmessage = (m) => {
      const p = pending.get(m.data.id);
      if (p) { pending.delete(m.data.id); m.data.error ? p.reject(new Error(m.data.error)) : p.resolve(m.data.value); }
    };
    window.__cockpitReady = true;
    return;
  }
});
// 握手：只发一个 hello。宿主用 event.source 认人。
parent.postMessage({ type: 'cockpit-hello' }, '*');
// 对外暴露 cockpit.*（契约 spec/03 §7.7）
window.cockpit = {
  tags: {
    get: (name) => ask('tags.get', { name }),
    list: () => ask('tags.list', {}),
  },
};
`;
const PROBE = `
(async () => {
  const wait = (ms) => new Promise(r => setTimeout(r, ms));
  for (let i = 0; i < 50 && !window.__cockpitReady; i++) await wait(50);
  if (!window.__cockpitReady) { parent.postMessage({ report: 'NO_PORT' }, '*'); return; }
  try {
    const v = await window.cockpit.tags.get('cpu.usage');
    parent.postMessage({ report: 'GOT', value: v, cockpitType: typeof window.cockpit }, '*');
  } catch (e) { parent.postMessage({ report: 'ERR', err: String(e) }, '*'); }
})();
`;
const CARDS = {
  'a.html': '<!doctype html><meta charset=utf-8><body>A<script type="module" src="./card.js"></script></body>',
  'b.html': '<!doctype html><meta charset=utf-8><body>B<script type="module" src="./card.js"></script></body>',
  'card.js': "import './bridge.js';\nimport './probe.js';\n",
  'bridge.js': BRIDGE,
  'probe.js': PROBE,
};

process.on('uncaughtException', (e) => out('UNCAUGHT ' + (e && e.stack ? e.stack : String(e))));
app.whenReady().then(() => {
  protocol.handle('cockpit', (req) => {
    const u = new URL(req.url); const name = path.basename(u.pathname);
    const body = CARDS[name];
    if (body === undefined) return new Response('nf', { status: 404 });
    const mime = name.endsWith('.js') ? 'text/javascript; charset=utf-8' : 'text/html; charset=utf-8';
    return new Response(body, { headers: { 'Content-Type': mime, 'Content-Security-Policy': CSP } });
  });
  const win = new BrowserWindow({ width: 900, height: 700, show: false,
    webPreferences: { preload: path.join(__dirname, 'preload.js'), contextIsolation: true, nodeIntegration: false, sandbox: true } });
  win.webContents.on('console-message', (_e, _lvl, msg) => out('[console] ' + msg));

  // 宿主侧的卡片注册表：iframe 元素 -> 卡片 id
  const registry = new Map(); // contentWindow -> cardId
  win.webContents.on('did-finish-load', async () => {
    await new Promise(r => setTimeout(r, 500));
    win.webContents.executeJavaScript(`
      window.__reg = (id, el) => { window.__map = window.__map || new Map(); window.__map.set(el.contentWindow, id); };
      'ok'
    `).catch(() => {});
    await new Promise(r => setTimeout(r, 3000));
    out('=== DONE ==='); app.quit();
  });
  win.webContents.on('ipc-message', () => {});

  const parent = `<!doctype html><meta charset=utf-8><body>
<iframe id="A" sandbox="allow-scripts" src="cockpit://card/a.html" style="width:300px;height:80px"></iframe>
<iframe id="B" sandbox="allow-scripts" src="cockpit://card/b.html" style="width:300px;height:80px"></iframe>
<script>
const iframes = { A: document.getElementById('A'), B: document.getElementById('B') };
const byWindow = new Map();
for (const [id, el] of Object.entries(iframes)) byWindow.set(el.contentWindow, id);
const TAGVALUES = { 'cpu.usage': { value: 37.2, unit: 'percent', status: 'ok', at: 1762910000123 } };

console.log('PARENT_cockpit_type=' + (typeof window.cockpit) + ' where=' + (window.cockpit && window.cockpit.where));\nwindow.addEventListener('message', async (e) => {
  const d = e.data;
  if (d && d.type === 'cockpit-hello') {
    // ★ 认人：只用 event.source，不看 origin（不透明源下 origin 是 null）
    const cardId = byWindow.get(e.source);
    if (cardId === undefined) { console.log('BRIDGE_REJECT unknown-source'); return; }
    const ch = new MessageChannel();
    ch.port1.onmessage = (m) => {
      const { id, type, payload } = m.data;
      if (type === 'tags.get') {
        const v = TAGVALUES[payload.name];
        ch.port1.postMessage(v ? { id, value: v } : { id, error: 'not_found' });
      } else { ch.port1.postMessage({ id, error: 'unknown_method' }); }
    };
    ch.port1.start();
    e.source.postMessage({ type: 'cockpit-port' }, '*', [ch.port2]);
    console.log('BRIDGE_GRANTED to=' + cardId + ' origin=' + e.origin);
  }
  if (d && d.report) console.log('CARD_REPORT ' + JSON.stringify(d) + ' sourceCard=' + byWindow.get(e.source));
});
</script></body>`;
  fs.writeFileSync(path.join(__dirname, 'parent.html'), parent);
  win.loadFile(path.join(__dirname, 'parent.html'));
}).catch((e) => { out('READY_FAIL ' + String(e)); app.quit(); });
```
