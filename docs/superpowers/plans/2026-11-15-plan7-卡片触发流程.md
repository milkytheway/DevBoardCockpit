## 〇 · 这一步要解决什么

> **用户原话**：「用户可以选择**本机**或者**客机**上的代码，选择后可以点击编译，
> 然后上传编译产物到板子上的选定位置，并可以点击加载运行。」

**现状**：流程层（计划 6 ✓）已经能在真板上跑通**一整条**「编译 → 直传 → 落位 → 装 → 跑」✓，
但**没有任何人能点它** ✗ —— `WorkflowService` 在全仓**零调用者** ✓（`docs/37` 就记了这条 ✓）。

**这一步**：把**卡片**接上去 ✓ —— 一张卡能起一条流程 ✓、能看阶段时间线 ✓。

**不做**（归别的轨 ✓）：MCP server（**计划 8** ✓）· GUI 的取消按钮（**外壳那条轨** ✓）·
路径选择器（**外壳那条轨** ✓ —— ADR-D35 D35-4 ✓）。

## 一 · 契约怎么说（**实现不许比它多，也不许比它少** ✓）

| 位置 | 规定 |
|---|---|
| `spec/03` §7.7 | `cockpit.workflows.list()` · `cockpit.workflows.run(id, inputs)` · `cockpit.workflows.status(runId)` ✓ |
| `spec/03` §3.3 | 有效流程权限 = **`permissions.workflows` ∩ 已授权的流程** ∩ **流程包已批准** ✓ |
| `spec/05` §八·B·B5 | **卡片侧是缩减投影** ✓：`stages` 只给 `stepId` / `kind` / `ok` / `verified` / `reason` ✓；**明细留在宿主与 agent 那边** ✓ |
| `spec/03` §7.7 | **所有方法都不抛异常** ✓：失败返回 `{ ok: false, reason }` ✓ |

> ⚠️ **本计划要关掉一条老欠账**：`docs/37` 的 **V3-M7** ✓ ——
> 「卡片侧的状态**会全泄**（`outputs` / `inputs` / `role` / `detail` / `value`）✓」
> → **计划 7 开工前必须先关** ✓（`docs/06` C18 ✓）→ **本计划 Task 2 一并做掉** ✓。

## 二 · 四个任务

### Task 1 · **卡级授权的第四维**接进判定

**问题**：`permissions.workflows` 这一维**在宿主侧没接线** ✓ ——
`permsFor`（`src/main/index.ts` ✓）返回的对象里**根本没有它** ✓ → 卡片就算声明了也白声明 ✓。

| # | 做什么 | 判据 |
|---|---|---|
| 1.1 | `CardApiPermission` 加一维 `'workflow'` ✓（**不许混进 `permissions.write`** ✓ —— 契约 §2.3 ✓） | 单测：注册表里 `workflows.run` 的 permission 是 `'workflow'` ✓ |
| 1.2 | 会话层的写判定分维度 ✓（`write` 看 `perms.write` ✓，`workflow` 看 `perms.workflows` ✓） | 单测：**不在 `permissions.workflows` 里 → `denied`** ✓ |
| 1.3 | `permsFor` 补上 `workflows: effectiveWorkflows(declared, grants.workflowIds(cardId))` ✓ | 单测：`effectiveWorkflows`（**现在一个测试都没有** ✓） |
| 1.4 | **规则 14**（`permissions.workflows` 里每个 id **不许通配符** ✓，且**必须是宿主里已声明的流程** ✓）—— 契约 `spec/03` §九 已经写了 ✓，**实现里没有** ✓ | 单测：带通配符的 `permissions.workflows` → 校验不过 ✓ |

### Task 2 · **卡片 API 三个方法**（含 **V3-M7** 的投影 ✓）

| # | 做什么 | 判据 |
|---|---|---|
| 2.1 | `CardServices` 加 `workflows` 端口 ✓（`list` / `run` / `status` ✓） | 单测：注册表里有这三个方法 ✓ |
| 2.2 | `workflows.run` 的 `scopeArg` 是 `'id'` ✓（**流程 id** ✓） | ✓ |
| 2.3 | **缩减投影** ✓（`spec/05` §八·B·B5 ✓）：`role` / `detail` / `value` / `audit_id` / `outputs` / `inputs` **一律不给卡片** ✓ | 单测：状态里**查不到** `outputs` / `inputs` / `role` / `detail` / `value` ✓（**V3-M7 关掉** ✓） |
