## 一 · 宿主侧地基（**六处缺口** ✓）

### Task 1 · 板型包的**脱敏**只读投影（**G1** ✓）

**要什么** ✓：
- `TagRuntime` 暴露**当前板型包**的只读视图 ✓（`pack` 是私有的 ✓）
- **但不能把原始 args 直接给 agent** ✓ —— `exec_regex` 的 `command` 与
  `script` 的 `path` + `interpreter` **必须挡掉** ✓（契约 v5 §2.4 的放行表 ✓）

**判据**：
1. `runtime.packView()` 返回**读数、轮询组、reader 的脱敏视图** ✓
2. **`exec_regex` 的 `command` 一个字都不在里面** ✓
3. **`script` 的 `path` 与 `interpreter` 一个字都不在里面** ✓
4. **`file_read` 的 `path` 在里面** ✓（它是**板上**路径 ✓ —— 契约说「哪个文件」✓）
5. **放行表按 `(kind, 参数名)` 判定** ✓ —— 不是按参数名单独判定 ✓

**放行表**（契约 v5 §2.4 的那张 ✓ —— **逐 kind 写死** ✓）：

| kind | 给 | 挡 |
|---|---|---|
| `proc_stat` | `stat_path`, `cpuinfo_path` | — |
| `meminfo` | `path` | — |
| `devfreq_load` | `path`, `measure` | — |
| `rknpu_load` | `path` | — |
| `thermal_zone` | `glob`, `type_map` | — |
| `file_read` | `path`, `glob`, `format`, `strip_trailing_null` | — |
| `exec_regex` | `pattern`, `format` | **`command`** |
| `script` | **（空）** | **`path`, `interpreter`, `format`** |

### Task 2 · 样本环形缓冲（**G2** ✓）

**要什么** ✓：`TagStore` 每个 tag 保留**最近若干个样本** ✓（现在只留最新一条 ✓）→
支撑 `sample_tag(name, n)` 与 `describe_tag.history` ✓。

**判据**：
1. 连续写 5 个样本 → `history(tag)` 拿得到**最近 5 个** ✓（**顺序：最旧 → 最新** ✓）
2. **超过容量 → 丢最旧的** ✓（环形 ✓）
3. **每个 tag 各自一份** ✓（不串 ✓）
4. **容量是实现细节** ✓（契约只说「最多 n 个，不足不补」✓ —— **不锁死** ✓）

### Task 3 · 活连接（**G3** ✓）

**要什么** ✓：`connected` 要能答「这条 profile 现在有活连接吗」✓。
→ `TerminalManager` 的 `LiveSession` **记 `profileId`** ✓ + 暴露**活着的 profile id 列表** ✓。
→ **不查 `runtime.status.profileId` 就算「连着」** ✓ —— 那个字段在 idle/error 时**仍有值** ✓。

**判据**：
1. 开一个终端会话 → 那条 profile 的 `connected` 是 `true` ✓
2. 关掉 → `false` ✓
3. **运行时连不上时**（`state = 'error'`）→ 那条 profile 的 `connected` 是 **`false`** ✓
   （**这是评审 I-1 抓的那条** ✓ —— 光看 `profileId` 会误报 `true` ✓）

### Task 4 · 卡片信息（**G4 + G5** ✓）

**要什么** ✓：`list_cards` 要给 `installed_at` / `status` / `missing_tags` / `unreadable_tags` ✓。

**判据**：
1. `installed_at` = **卡片目录的 mtime** ✓（**不是**「装上的时刻」✓）
2. `status` 三档 ✓（`ok` / `degraded` / `invalid` ✓）
3. **`missing_tags` 与 `unreadable_tags` 分开** ✓ —— 一个是「板上根本没有」✓，
   一个是「现在读不出来」✓
4. **通配实例在读数里缺席 → 不算 missing** ✓（评审 C-2 的那条 ✓）

## 三 · 写侧工具（**2 个** ✓ —— agent 的交互权限）

### Task 7 · `execute_action`（**G7 + G8** ✓）

**要什么** ✓：
- **执行器加「agent 授权模式」** ✓（`granted` = 包里的全部动作 ✓ —— 契约 v5 §2.4.1 细则 1 ✓）
- **执行器加 `dry_run` 分支** ✓（编码之后、执行之前 ✓ —— **不执行、不回读、不写审计** ✓）

**判据**：
1. **动作不在包里 → `not_found`** ✓（**不是 `denied`** ✓ —— 顺序有讲究 ✓）
2. **`reversible` 且参数在 `guard` 域内 → 直接执行** ✓ + **记审计** ✓
3. **`destructive` → `needs_confirmation`** ✓ + **带 `confirm_id`** ✓
4. **参数超出 `guard` → `needs_confirmation`** ✓ + **带 `guard_exceeded: true`** ✓
5. **`dry_run` → 返回编码后的最终命令** ✓ + **不执行** ✓ + **不写审计** ✓
6. **`dry_run` 在确认之前** ✓（destructive 动作的 dry_run **也要给命令** ✓ —— 评审 I-13 ✓）
7. **审计行的 actor 是 `agent`** ✓（不是 `card:xxx` ✓）

### Task 8 · `confirm_action`

**要什么** ✓：递一次确认请求 ✓（**不批准** ✓）+ `confirm_id` + `expires_at`（毫秒 ✓）。

**判据**：
1. **`confirm_id` 此刻无效** ✓（带它去 `execute_action` 仍然 `needs_confirmation` ✓）
2. **人批了之后才有效** ✓
3. **`expires_at` 是毫秒** ✓
