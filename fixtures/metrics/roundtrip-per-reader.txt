# 每个 reader 的输出用**自己的** marker 隔开：
#
#   echo '###R cpu STAT'; ...; echo '###E cpu'; echo '###R gpu LOAD'; ...; echo '###E gpu'
#
# ⚠️ 这个文件是**构造**的：内容取自 metrics/snapshot-sample.txt（真实抓取），

# 契约格式下的真机抓取样本仍值得补（只增不改）。
#
# 解析要点（实现层要对的行为）：
#   1. 看到 `###R <reader> <KIND>` 开始一个 section，遇到 `###E <reader>` 结束；
#   2. section 为空 = 该 reader 本轮没产出 = 报 unavailable，**不能报 0**；
#   3. 一个 reader 的 section 坏了，不影响同组其他 reader；
#   4. `###R` / `###E` 必须配对，reader 名必须一致。
#
